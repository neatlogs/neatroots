# Code of conduct

neatroots follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in this repository's issues, pull requests and discussions, and wherever someone represents
neatroots.

In short: be respectful, critique ideas and code rather than people, and keep discussion on topic.
Harassment, personal attacks and publishing someone's private information aren't tolerated.

## Reporting

Use GitHub's **Report content** on the comment, issue or pull request (in its `…` menu), and choose
**Report to repository admins**. The maintainers in [MAINTAINERS.md](MAINTAINERS.md) review reports
privately and act on them as the Contributor Covenant's enforcement guidelines describe, from a warning
to a ban from the project.
